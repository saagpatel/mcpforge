# SQLite Analytics Server

A read-only MCP server for querying and exploring a local SQLite analytics database with safe SELECT execution and schema inspection.

Generated by mcpforge.

## Components

### Tools


#### `list_tables`

List all tables available in the SQLite database.





Parameters:


Returns: `dict`


Error cases:

- database file not found

- database connection failed




#### `describe_table`

Return the schema of a specific table, including column names, types, nullability, and default values.





Parameters:

- `table_name` (`str`): The name of the table to describe


Returns: `dict`


Error cases:

- table not found

- database connection failed

- invalid table name




#### `run_select_query`

Execute a safe, read-only SELECT query against the database. Mutating SQL statements (INSERT, UPDATE, DELETE, DROP, ALTER, CREATE, etc.) are rejected. Results are capped at a configurable row limit.





Parameters:

- `query` (`str`): A SELECT SQL query to execute against the database

- `row_limit` (`int`, optional): Maximum number of rows to return


Returns: `dict`


Error cases:

- mutating SQL statement detected and rejected

- SQL syntax error

- referenced table or column does not exist

- row_limit exceeds maximum allowed value

- database connection failed

- query execution timeout




#### `get_query_history`

Retrieve the history of SELECT queries executed in the current server session, including timestamps and row counts returned.





Parameters:

- `limit` (`int`, optional): Maximum number of history entries to return, most recent first

- `filter_keyword` (`str | None`, optional): Optional keyword to filter history entries by query text


Returns: `dict`


Error cases:

- limit must be a positive integer




#### `get_table_sample`

Return a small sample of rows from a table to help understand its contents without writing a full query.





Parameters:

- `table_name` (`str`): The name of the table to sample

- `sample_size` (`int`, optional): Number of sample rows to return


Returns: `dict`


Error cases:

- table not found

- sample_size must be a positive integer

- database connection failed




#### `get_table_row_count`

Return the total number of rows in a specified table.





Parameters:

- `table_name` (`str`): The name of the table to count rows in


Returns: `dict`


Error cases:

- table not found

- database connection failed





### Resources


- `sqlite://overview`: A high-level overview of the SQLite database including all table names, row counts, and column summaries — useful as context before querying.



### Prompts


- `explain_query_results`: Generate a plain-English explanation of the results returned by a SELECT query, highlighting trends, outliers, and key takeaways suitable for a non-technical audience.



## Setup

Prerequisites:

- Python 3.12+
- uv
- FastMCP 3.x


Copy `.env.example` to `.env` and fill in the required values:

```bash
cp .env.example .env
```

Required environment variables:


- `DATABASE_URL`

- `DATABASE_PATH`



Install and test:

```bash
uv sync
uv run pytest
```

## Run Locally

Direct Python:

```bash
uv run python server.py
```

FastMCP stdio:

```bash
fastmcp run server.py
```

FastMCP HTTP:

```bash
fastmcp run fastmcp.json --transport http --host 127.0.0.1 --port 8000
```

## MCP Client Configuration

Local stdio client config:

```json
{
  "mcpServers": {
    "sqlite-analytics-server": {
      "command": "uv",
      "args": ["--directory", ".", "run", "python", "server.py"]
    }
  }
}
```

HTTP client config:

```json
{
  "mcpServers": {
    "sqlite-analytics-server": {
      "url": "http://localhost:8000/mcp/",
      "transport": "streamable-http"
    }
  }
}
```

## Security Notes

- Keep secrets in environment variables; never paste API keys into prompts.
- Require approval for sensitive write, delete, or external-send actions.
- Connect remote MCP clients only to trusted servers and review shared data.
- Do not pass MCP client bearer tokens through to downstream APIs.
- Log and review data sent to third-party services when running remotely.
