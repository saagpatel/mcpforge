# Safe Workspace File Reader

An MCP server that provides read-only access to a sandboxed workspace directory with tools for listing, reading, searching, and summarizing files.

Generated by mcpforge.

## Components

### Tools


#### `list_files`

List files and directories within the workspace, optionally filtered by a subdirectory path. Blocks path traversal attempts.





Parameters:

- `subpath` (`str`, optional): Relative subdirectory path within the workspace to list. Defaults to the root of the workspace.

- `recursive` (`bool`, optional): Whether to list files recursively in all subdirectories.

- `include_hidden` (`bool`, optional): Whether to include hidden files and directories (those starting with a dot).


Returns: `dict`


Error cases:

- path traversal detected

- subpath does not exist

- subpath is not a directory




#### `read_file`

Read the text contents of a file within the workspace. Blocks path traversal and binary files above a size threshold.





Parameters:

- `filepath` (`str`): Relative path to the file within the workspace to read.

- `encoding` (`str`, optional): Text encoding to use when reading the file.

- `max_bytes` (`int`, optional): Maximum number of bytes to read from the file to prevent reading very large files.


Returns: `dict`


Error cases:

- path traversal detected

- file not found

- file exceeds max_bytes limit

- file is not valid text or encoding mismatch

- filepath points to a directory




#### `search_file_contents`

Search for a text pattern across files in the workspace and return matching lines with their file paths and line numbers.





Parameters:

- `pattern` (`str`): The text or regex pattern to search for within file contents.

- `subpath` (`str`, optional): Relative subdirectory path within the workspace to scope the search.

- `file_glob` (`str`, optional): Glob pattern to filter which files are searched, e.g. '*.py' or '*.txt'.

- `use_regex` (`bool`, optional): Whether to treat the pattern as a regular expression.

- `case_sensitive` (`bool`, optional): Whether the search should be case-sensitive.

- `max_results` (`int`, optional): Maximum number of matching lines to return.


Returns: `dict`


Error cases:

- path traversal detected

- subpath does not exist

- invalid regex pattern

- no files matched file_glob




#### `get_file_metadata`

Retrieve metadata for a specific file or directory in the workspace, including size, modification time, and type.





Parameters:

- `filepath` (`str`): Relative path to the file or directory within the workspace.


Returns: `dict`


Error cases:

- path traversal detected

- file or directory not found




#### `summarize_file_metadata`

Summarize metadata for all files in the workspace or a subdirectory, including total count, total size, file type breakdown, and most recently modified files.





Parameters:

- `subpath` (`str`, optional): Relative subdirectory path within the workspace to summarize.

- `top_n_recent` (`int`, optional): Number of most recently modified files to include in the summary.


Returns: `dict`


Error cases:

- path traversal detected

- subpath does not exist

- subpath is not a directory





### Resources


- `workspace://summary`: Read-only summary of the workspace root, including total file count, total size, file type breakdown, and top recently modified files.



### Prompts


- `review_file_safely`: Generate a safe review prompt for a given workspace file, asking the model to analyze its contents without executing or modifying anything.



## Setup

Prerequisites:

- Python 3.12+
- uv
- FastMCP 3.x


Copy `.env.example` to `.env` and fill in the required values:

```bash
cp .env.example .env
```

Required environment variables:


- `WORKSPACE_ROOT`



Install and test:

```bash
uv sync
uv run pytest
```

## Run Locally

Direct Python:

```bash
uv run python server.py
```

FastMCP stdio:

```bash
fastmcp run server.py
```

FastMCP HTTP:

```bash
fastmcp run fastmcp.json --transport http --host 127.0.0.1 --port 8000
```

## MCP Client Configuration

Local stdio client config:

```json
{
  "mcpServers": {
    "safe-workspace-file-reader": {
      "command": "uv",
      "args": ["--directory", ".", "run", "python", "server.py"]
    }
  }
}
```

HTTP client config:

```json
{
  "mcpServers": {
    "safe-workspace-file-reader": {
      "url": "http://localhost:8000/mcp/",
      "transport": "streamable-http"
    }
  }
}
```

## Security Notes

- Keep secrets in environment variables; never paste API keys into prompts.
- Require approval for sensitive write, delete, or external-send actions.
- Connect remote MCP clients only to trusted servers and review shared data.
- Do not pass MCP client bearer tokens through to downstream APIs.
- Log and review data sent to third-party services when running remotely.
