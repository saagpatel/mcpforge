# Hosted Auth Tickets API

A small authenticated ticket API for hosted generation smoke tests.

Generated by mcpforge.

## Components

### Tools


#### `get_ticket`

Get a ticket


- Source operation: `GET /tickets/{ticket_id}`


- Tags: tickets, read


- Auth profile: `api_key`


- Auth credential env var: `HOSTED_AUTH_API_KEY`


Parameters:

- `ticket_id` (`str`, path): Ticket identifier.

- `include_history` (`bool`, query, optional): Whether to include status history.


Returns: `dict`



#### `create_ticket_note`

Create a ticket note


- Source operation: `POST /tickets/{ticket_id}/notes`


- Tags: tickets, write


- Auth profile: `api_key`


- Auth credential env var: `HOSTED_AUTH_API_KEY`


Parameters:

- `ticket_id` (`str`, path): Ticket identifier.

- `body` (`dict`, body): Request body matching the object schema


Returns: `dict`






## Setup

Prerequisites:

- Python 3.12+
- uv
- FastMCP 3.x


Copy `.env.example` to `.env` and fill in the required values:

```bash
cp .env.example .env
```

Required environment variables:


- `BASE_URL`

- `HOSTED_AUTH_API_KEY`

- `REQUEST_TIMEOUT_SECONDS`

- `MCPFORGE_SERVER_API_KEY`




## Runtime Profiles


Auth profile: `api-key`.

## Remote MCP Readiness

Deployment profiles:

- Local stdio: use the `config.json` command for desktop clients.
- Local HTTP: run `fastmcp.json` on `127.0.0.1` for connector testing.
- Production HTTP: put the server behind TLS, logging, and an explicit auth boundary.
- Remote connector: expose only the `/mcp/` endpoint and review shared data before connecting clients.

Readiness checklist:

- Fill every value in `.env.example`; never commit filled secrets.
- Use `MCPFORGE_SERVER_API_KEY`, JWT, or a gateway policy before exposing HTTP publicly.
- Keep downstream API keys separate from MCP client tokens; do not pass client bearer tokens downstream.
- Require human approval for sensitive write, delete, external-send, or cross-account actions.
- Log request timing and tool names, but avoid logging raw secrets or full private payloads.

## Security Notes

- Keep secrets in environment variables; never paste API keys into prompts.
- Require approval for sensitive write, delete, or external-send actions.
- Connect remote MCP clients only to trusted servers and review shared data.
- Do not pass MCP client bearer tokens through to downstream APIs.
- Log and review data sent to third-party services when running remotely.
